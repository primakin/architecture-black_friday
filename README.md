# pymongo-api

## Как запустить итоговый проект
```shell
cd sharding-repl-cache
docker compose up -d
./scripts/mongo-init.sh
```
## Как проверить
Откройте в браузере http://localhost:8080
Список доступных эндпоинтов, swagger http://localhost:8080/docs
